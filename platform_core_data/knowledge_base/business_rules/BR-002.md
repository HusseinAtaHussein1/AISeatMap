## Rule

Branch's **Supplier Routing** section (`discovery/Branch_Add.md` — a dynamically-generated block of
checkbox + dropdown + description rows, one per configured supplier) determines which suppliers a
Branch is allowed to return flight results from.

- Enabling a supplier there (e.g. checking "EgyptAir NDC") restricts that Branch's flight search
  results to only the enabled supplier(s).
- **Every Agency under that Branch automatically inherits the Branch's Supplier Routing
  configuration** — Agencies do not configure their own supplier routing independently.
- Functional consequence: a flight search (e.g. `CAI → JED`) performed either directly from the
  Branch or from any Agency under it should return results **only** from the suppliers enabled on
  that Branch. Example: if only EgyptAir NDC is enabled on a Branch, a `CAI → JED` search from that
  Branch or any of its Agencies should return EgyptAir flights only — no other supplier's results.
  **Caveat ([[BR-004]]):** this "only that airline" framing is specific to a single LCC supplier and
  still allows a multi-carrier itinerary naming that LCC as a participant; it does not apply at all
  to a GDS supplier, which is expected to return multiple airlines by design.

## Hierarchy confirmation

Confirms the existing `architecture.md` Reference Data chain: Branch sits under Operating Country,
Agency sits under Branch (`Operating Country → Branch → Agency`) — Supplier Routing is configured at
the Branch level and flows down, never configured per-Agency.

## How to Apply

- Not yet a test case — no Discovery or Test Design pass has exercised this functionally (e.g., no
  live search comparing Branch-enabled-supplier vs. actual returned results has been run).
- When Branch/Agency Test Design next covers Supplier Routing or flight search scoping, design
  against this confirmed behavior rather than treating it as an open question: (1) toggling suppliers
  on a Branch should change what an Agency-level search under it can return; (2) an Agency should
  never surface a supplier its parent Branch doesn't have enabled.
- Relevant to any future regression test that exercises Flight Search (`Booking-Mid Office` module)
  scoped by Branch/Agency identity.
