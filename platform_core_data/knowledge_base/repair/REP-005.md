## Execution Context

EXEC-20260713-001-REPAIR (Agency Repair Round 2) — `tests_SHAFT`, TC-AGENCY-001
(`addAgencyHappyPathEntersApprovalQueue`) and TC-AGENCY-004
(`addAgencyBusinessTypeSelectionEstablishesBehavior`), Branch dropdown option selection.

## What Happened

Once REP-004's wrapper-click fix let the Branch dropdown actually open, the option-matching
locator (`//span[contains(text(), '%s')]`, later `//li[@role='option']//span[contains(...)]`) still
threw `MultipleElementsFoundException`. Live DOM inspection (via `tools/browser_driver`, a Node/
Playwright script run against the same STG environment, outside the SHAFT/Selenium suite itself)
showed every option renders as `"{Name} (BRNxxx)"` (e.g. `"Test (BRN2)"`), and this environment's
~150 Branch records include several whose name contains "Test" as a substring
(`"TESTING (BRN111)"`, `"Test NDC MSG (BRN221)"`, `"testtttt (BRN133)"`, etc.) — any `contains()`
match, however scoped to the option-list role, still hit more than one. Repaired by (1) typing into
the dropdown's own filter input (`p-dropdown-filter`) first to narrow the rendered list, then (2)
matching via `starts-with(normalize-space(text()), '{value} (')` — the trailing `" ("` disambiguates
`"Test (BRN2)"` from `"Test NDC MSG (BRN221)"`, which a plain `starts-with(..., 'Test ')` would not.

## General Pattern (candidate for platform promotion — not yet promoted, needs explicit approval)

**When a PrimeNG dropdown's option list renders values as `"{Name} ({Code})"` and the target
environment has many records sharing a common name substring, do not match by `contains()` alone —
even scoped to the option-list role. Use the dropdown's own filter input to narrow the rendered
list first, then match with `starts-with(normalize-space(text()), '{value} (')` to disambiguate
exact-prefix matches from longer names that happen to start the same way.** This generalizes beyond
Agency's Branch field to any PrimeNG dropdown populated from a live, growing record set where names
are not guaranteed unique as substrings (Branch/Agency/Staff selection dropdowns across this
project's Admin module all share this shape).
