- **Category:** Observation
- **Severity:** N/A (Observation category, per §5.4)

- **Evidence Category:** Human Observation (§17) — screenshots supplied directly by the human operator during User-guided exploration; not independently reproducible by the agent within this run. Per §18, this caps Status below `Confirmed` regardless of clarity.
- **Status:** Needs Human Review
- **Business Risk:** None identified for this run — Import PNR and Import Booked PNR are explicitly Out of Scope (Project Context §3), so this does not affect any in-scope acceptance criteria. Worth noting only because it means `architecture.md`'s standing Navigation Model may be stale or role-scoped.
- **Technical Risk:** None identified as an application defect — **now explained** (see Root Cause Hypothesis update below): `odeysysadmin` and `E.Saady` are two distinct, legitimate roles (Super Admin vs. Admin) with different feature access, per direct stakeholder clarification 2026-07-11. Residual risk is only that `architecture.md`'s Navigation Model doesn't yet document per-role nav differences.
- **Module:** Global navigation (observed while in Master → Supplier → Credential Routes Filter)
- **Workflow:** N/A — passive observation of the persistent top nav bar across all three Credential Routes Filter screens (Add/List/Edit)
- **Description:** `architecture.md`'s Navigation Model documents the top nav bar as 13 items: Dashboard · Admin · Master · Rule Engine · Settings · User Management · Booking-Mid Office · Profile · Reports · PNR Query · Transfer PNR · Import PNR · Import Booked PNR. All three screenshots from this session (Add/List/Edit Routes Filter) show only 11 items — the same list minus "Import PNR" and "Import Booked PNR" — with no overflow/"more" menu visible.
- **Expected Behavior:** Per `platform_core_data/architecture.md` §"Navigation Model": nav bar includes "Import PNR" and "Import Booked PNR" as the 12th/13th items. (Note: `architecture.md` is standing application documentation, not the Project Context itself — Project Context does not separately restate the full nav bar, and Import PNR/Import Booked PNR are Out of Scope per Project Context §3 regardless of whether they're visible.)
- **Actual Behavior:** Nav bar shows exactly 11 items, ending at "Transfer PNR" — Import PNR and Import Booked PNR absent, consistently across 3 separate page loads.
- **Steps to Reproduce:** Log in as `odeysysadmin` at `http://192.168.1.70` → navigate to any Master screen → observe top nav bar.
- **Investigation/Recovery Result:** Not applicable — this is not a failure/error condition subject to the Investigation & Recovery Engine (§5.7); it is a static structural observation, consistent across all 3 screenshots (no retry needed to "resolve" it).
- **Investigation Notes:** Not a Validation/Navigation/Authorization candidate per §5.8's boundary-probe list, so no additional boundary probing performed. Root cause updated 2026-07-11 via direct stakeholder clarification (see below) rather than in-app probing.
- **Root Cause Hypothesis:** **Confirmed via stakeholder clarification, 2026-07-11** (Aymoon, Business Analyst/Product Owner role for this project): NDC has multiple distinct Admin-tier roles — **Super Admin** (`odeysysadmin`) and **Admin** (`e.saady`) — with different feature access; some features apply only to one tier (e.g., per the same clarification, Super Admin cannot complete the Booking Cycle/book a ticket, unlike Admin). The reduced 11-item nav bar for `odeysysadmin` is consistent with this being a genuine role-based restriction, not a documentation error or account mix-up. Confidence: 90% (direct stakeholder statement; Evidence Category for this specific clarifying fact is Human Observation — a human reporting domain knowledge to the agent — so it still cannot itself promote this Finding's Status to `Confirmed` per §18, but it materially resolves what was previously an open hypothesis). Supporting Evidence: user's in-session statement 2026-07-11 naming both roles and the Booking Cycle example. Unknowns: the *complete* list of features/modules that differ between Super Admin and Admin (only the nav-bar difference and the Booking Cycle example are confirmed so far) — see new FINDING-004 for the broader role-model gap this surfaces in the Project Context.
