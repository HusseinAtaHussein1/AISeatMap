> **Blocked, 2026-07-18 (FINDING-008):** the original design — create a `QA_SPIKE_` Branch (Pending),
> then reject that same record — is not achievable. Live investigation confirmed a Pending Branch
> never appears in the List/Grid at all: not via Search (zero results after a full 60s retry), not
> via the default no-Search view (page 1 shows 10 `Approved` records, none matching), and the
> Status filter only has Inactive/Active/Both — no Pending option exists. This mirrors the still-open
> Activate Agency blocker exactly. User confirmed (2026-07-18) the fix is to reject an **Approved**
> test record instead of the just-created Pending one, but how a Pending Branch becomes Approved is
> itself unconfirmed — user asked for this to be investigated live as a follow-up. Until then this
> test case cannot execute; the rest of the Branch module (TC-BRANCH-001–005, 008) is unaffected and
> passing.
