- **Title:** Several fields/behaviors described in the approved v3 Agency Test Design do not exist in the live Add/Update Agency form, and the Actions-column Approve/Reject visibility rule differs from what was specified
- **Category:** Requirement/Test-Design Gap
- **Severity:** Medium
- **Severity Reason:** These are approved (Stage 3, 2026-07-18) test cases whose steps reference UI elements this run's live inspection could not find at all — automating them as written would require fabricating locators, which this platform's own history (FINDING-002's false-positive TC-AGENCY-001) treats as a serious anti-pattern.
- **Confidence Score:** 85% — single live pass against `.70`, full-page screenshot of the entire Add form confirmed no scroll/collapsed section was missed (Send For Approval/Cancel buttons visible at the bottom of the same capture).
- **Evidence Category:** Direct Observation (live browser session via `tools/browser_driver`, 2026-07-18, `.70`)
- **Status:** Needs Human Review
- **Business Risk:** Low-Medium — if these fields/behaviors are meant to exist and simply haven't shipped yet, that's a real scope gap between requirements and the deployed app. If they were never meant to exist, the Test Design has stale/speculative cases that should be corrected or retired.
- **Technical Risk:** N/A — UI/requirement mismatch only.
- **Module:** Admin / Agency (Add, Update, List/Actions)
- **Workflow:** Add Agency (PCC Credentials, Payment Settings, Product Access, Draft), Agency List Actions (Approve/Reject visibility)
- **Description:** Live full-page inspection of `/admin/agency/add` (2026-07-18, `.70`) found the following discrepancies against the approved v3 Test Design (`runs/RUN-20260718-001/test_design/NDC_TestCases_Agency.md`):
  1. **No "Airline Supplier Credential (PCC)" section anywhere on the form** — `TC-AGENCY-CREATE-031`, `-032`, `-033` describe PCC credential fields (Amadeus/Galileo/Sabre filters, mandatory Credential fields) that were not observed, under any of Core/Classification/Owner/Documents/Sales Contact/Bank/Payment/Product Access/Agency Features. Not gated behind IATA Agency = Yes either (not independently confirmed — see Recommendation).
  2. **No "Save as Draft" button** — `TC-AGENCY-CREATE-035` describes one; the form's only two buttons are `Cancel` and `Send For Approval`.
  3. **Product Access Details section is simpler than described** — only `Select Product` (Flight/Others) and `Enable Search Limit` (checkbox, default checked, with a read-only "Search Limit Category: A" indicator) exist. `TC-AGENCY-CREATE-029`/`-030`'s "Status Column, Credential name, Description" mandatory sub-fields were not found.
  4. **Agency Features section has fields not in the Test Design at all**: `Transfer Pnr Option` and `Blue Command Screen` toggles exist alongside the documented `Import PNR Option` (`TC-AGENCY-CREATE-034`) — an omission in the Test Design's coverage, not a defect in the app.
  5. **Payment Settings' Credit Limit / Top-Up Limit / Credit Terms (Days) have live server-side defaults** (50000 / 500000 / 1) even when left blank on Add — `TC-AGENCY-CREATE-025`'s "numeric-only fields reject non-numeric input" framing doesn't address whether blank submission is itself valid (it evidently is).
  6. **Actions-column Approve/Reject visibility does not match `TC-AGENCY-ACTIONS-002`'s "shown only for Pending" rule** — live observation (`.70`) found Approved rows showing a thumbs-down (re-reject/deactivate) with no thumbs-up, and a Rejected row showing a thumbs-up (re-approve) with no thumbs-down. Both icons together were seen only on Pending rows. This reads more like a single-icon-per-current-status toggle than the Test Design's two-buttons-only-on-Pending model.
- **Expected Behavior:** Not independently defined outside the Test Design itself — whether PCC/Draft/detailed Product Access are (a) not yet built, (b) gated behind a role/config this Admin session didn't have, or (c) never real requirements to begin with is an open question this platform will not guess at further.
- **Actual Behavior:** See Description.
