# OrangeHRM Knowledge Base

Project Knowledge for OrangeHRM only — never consulted by any other project (`pipeline/pipeline.md` §10.6). Resolved alongside Platform Knowledge (`platform/knowledge/`) in the fixed order defined in `pipeline/pipeline.md` §10.2.

| Folder | Contains |
|---|---|
| `automation/` | Reusable code-asset notes specific to OrangeHRM's automation package |
| `diagnosis/` | Evidence-gathering findings specific to OrangeHRM |
| `repair/` | Execution-confirmed repair records for OrangeHRM, each citing the Platform pattern (if any) it implements |
| `execution/` | Execution history specific to OrangeHRM |
| `application/` | Application findings, known behaviors, module relationships |
| `ui/` | UI observations, navigation knowledge, screen inventory |
| `findings/` | Discovery artifacts / findings not otherwise categorized |
| `business_rules/` | Business rules discovered from OrangeHRM |
| `lessons_learned/` | OrangeHRM-specific lessons learned |

A pattern proven out here may be proposed for promotion to Platform Knowledge — see `pipeline/pipeline.md` §10.5. Promotion always requires explicit human approval; nothing is promoted automatically.

Update `INDEX.md` in this directory whenever a document is added.
